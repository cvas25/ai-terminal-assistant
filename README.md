# AI Terminal Assistant

A terminal-based AI assistant built in Python as part of my AI Engineering roadmap. This project demonstrates how to build a real AI application using the OpenAI API, conversation memory, tool calling, JSON storage, and modular software architecture.

---

## Features

- 🤖 Ask questions using OpenAI GPT-5.5
- 💬 Multi-turn conversation memory
- 📝 AI-powered note saving through tool calling
- 📂 Save and load notes using JSON
- 🌐 HTTP communication with the OpenAI API
- 🏗️ Modular Python architecture
- 🔐 Secure API key management using environment variables

---
