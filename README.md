# AI Terminal Assistant

A terminal-based AI assistant built in Python as part of my AI Engineering roadmap.

## Overview

This project was built to learn the fundamentals of AI engineering by creating a real application that communicates with the OpenAI API. The project also demonstrates modular Python architecture, JSON data storage, HTTP requests, environment variables, and Git version control.

## Features

## Features

- Ask questions using GPT-5.5
- Multi-turn conversation memory
- AI-powered note saving using tool calling
- Save and load notes with JSON
- Modular Python architecture
- OpenAI API integration

## Technologies Used

- Python
- OpenAI API
- JSON
- Requests
- python-dotenv
- Git
- GitHub
